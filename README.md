# CMS School Operations launcher

A home-screen shortcut for the Central Montessori School staff portal.

The portal runs on Google Apps Script, which cannot give an iPhone the icon
for a home-screen shortcut. This page carries the icons and nothing else:
add it to the home screen, and opening it goes straight on to the portal's
sign-in page. Nothing is signed in, stored or sent here.

This repository is a published copy. It is generated from the portal's own
repository; changes made here directly are overwritten.
